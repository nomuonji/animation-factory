# 見本を測って再現する

詳細と頼み方の型は `docs/reference-replication.md`。道具は `tools/reference/reference.py`。

## 守ること
- 見本は定規。測るだけで、見本のフレーム・音声を出力やコミットに入れない（`outputs/` は git 管理外）。
- 見本は自分の動画か、型・間・レイアウトの研究として参照する動画に限る。他人の映像・音声は出力に持ち込まない。
- 自動で出るのは technical な近さまで。見た目とテンポの良し悪し（editorial）は人が見て聞いて決める。
- 動画固有の分岐を runtime に足さない。数値は `productions/<id>/` のデータへ書く。
- 前の MP4 は残し、新しい MP4 として書き出す。

## 担当は3つに分ける

### 1. 構成（テーマ → 順位・台本・コメント）
- 台本と素材は見た目合わせの間は変えない（変えると比較ができなくなる）。
- 各本に「選んだ理由」「自分の見解」を入れる。型だけを写した量産にしない。

### 2. 素材集め・見た目合わせ
1. `python tools/reference/reference.py measure <見本>` でカット点・コンタクトシートを出し、コマを見て部品を洗い出す（背景・タイトル・順位・コメント枠・素材）。
2. 単色の部品ごとに `track --color '#RRGGBB'` で位置・大きさ・イージングを取る。写真など色で追えない部品は、コンタクトシートから手で座標を取る。
3. 取った数値（座標・大きさ・出る/消えるコマ・イージング）を `productions/<id>/` のデータに書く。
4. **先に冒頭を合わせ**、それから全体を仕上げる。
5. `compare <見本> <出来上がり>` で `worst-frames.jpg` を見て、差の大きい瞬間が部品のずれかを判断し、直して再書き出し。

### 3. 音声と書き出し
- 声の間は別に調整する。語尾は削らず、話し終わってから次が始まるまでの**待ち時間だけ**を詰める。話す速さは変えない。
- コメントの表示タイミングと順位の切り替えも、詰めた間に合わせる。
- `compare` の `speechGaps.medianGapRatio` が 1.0 に近づくまで調整（目安 0.85〜1.15）。
- 書き出し後、決めた数値と間の詰め方をこのスキルか `productions/<id>/` に残す。

## 報告で区別すること
- 「測定した」「数値が見本に近づいた」（technical）と、「見て聞いて良かった」（editorial）を混ぜない。
- 声のライセンス（クレジット表記・収益化可否）と素材の権利を、公開前に確認済みか未確認かを書く。
