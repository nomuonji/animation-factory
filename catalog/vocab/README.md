# CEFR word levels for English lessons

- `octanove-vocabulary-profile-c1c2-1.0.csv` — Octanove Vocabulary Profile C1/C2 ver 1.0, Octanove Labs,
  from https://github.com/openlanguageprofiles/olp-en-cefrj . License: CC BY-SA 4.0
  (https://creativecommons.org/licenses/by-sa/4.0/). Unmodified copy. Videos that use its levels credit it in
  the description.

Use: `python tools/shorts/shorts.py vocab --level C2 --pos adjective` lists words of that level that no lesson
has used yet. The level is a guide; pick words natives actually use (avoid technical or archaic ones).
