# ショートドラマのメタ設計（3D Shorts 用テンプレ）

演技で見せる縦型ショート（コント・寸劇）を作る前に決めること。中身のネタは毎回違っても、**観客がどこで止まり、何を期待し、どこで回収されるか**の骨組みは型にできる。

- 型の正本: `catalog/skit-formats.json`（フォーマット・役割・フック型・タイトル型・数値の目安）
- 雛形: `templates/skit3d.json` を `productions/<id>/scene3d.json` にコピーして埋める
- 自動チェック: `node tools/three/design-lint.mjs <id>`（レンダリング時にも自動実行。エラーがあると止まる）
- 編集審査: `short-form-video-direction` スキル（My Portal）の6軸。構造チェックの合格は面白さの保証ではない

## 0. 現実の土台（2026-11-07 再発防止）

ズレは**一つだけ**。それ以外の場所・出来事・小道具・人の行動は、現実にあるとおりにする。

- `design.reality.place` に舞台、`normalEvent` にその場所で現実に普通に起きる出来事、`onlyBreak` に外す1点を書く
- **手持ちのセットに合わせて舞台を変えない**。合うセットがなければ `src/three/sets.ts` に作る（lint は `setPlaces` で、セットと舞台が食い違うと止める）
- 失敗例: 「試食に面接」をコンビニのセットで作った。コンビニに試食はないので、ネタとは別の違和感が先に立つ
- `design.payoffMechanism` にオチの仕組みを書く。直近の作品と同じ仕組みなら lint が警告する（例: 2本続けて「逃げ道にも手続き」）
- `design.ideation` に発想の手順と検討した案の数を書く。過去の候補リストの流用で済ませない

### 狙いすぎない（2026-11-07 本人評価）

- 好評だった案: 面接の定番質問「自分を動物に例えると？」にカエル帽の応募者が「カエルです」と答え、最後に聞き返された柴バーガーの面接官が「バーガーです」と答える（`productions/doubutsu-tatoeru`）。現実の場面をそのまま使い、ずらすのは一点だけ。説明も決め台詞もない
- 「狙いすぎ」と言われた案: ボケのために用意した小道具を見せびらかす（身分証として化石、お薬手帳として魔導書）。作った決め台詞で締める
- 自問: 笑いが、場面とキャラが元からそうであることだけで起きているか。足した物や台詞がないと成立しない案は落とす
- 案は3つ程度に絞って本人に見せ、選んでもらってから作る

### 尺と配役（2026-11-07 本人指示）

- 「もっと尺長くして」: 3D コントは **35〜50秒** を目安にする（「赤べこの証明写真」21秒は短い）。伸ばすのは段（escalate）を増やすことで。同じズレが一段ずつ具体的・大きくなる二段目・三段目の発見を足す。無言の間・同じ台詞の繰り返し・説明で水増ししない
- 配役に優先順位をつけない。メインキャラ（悪魔・赤べこ）も 100Avatars も、案に一番合うものを選ぶ

## 1. 三つの約束を揃える（タイトル × 0秒の画 × 最初の一言）

フィードで観客が受け取るのは、ほぼ同時に届く三つの情報。三つとも**同じ約束**を、**別の層**で言う。同じ文言を繰り返さない。

| 層 | 役割 | 規則 |
|---|---|---|
| タイトル（`design.title`） | どんな世界・状況かを言う。動画上部に常時表示（`titleOnScreen`: always/hook/none、表示文言だけ変えるなら `titleScreenText`）。投稿時のタイトルにも同じ文言を使う | 28字以内。具体名詞を前半に。オチ（payoff）は言わない。煽り記号を重ねない |
| 0秒の画＋画面文字（`hook.firstFrame` / `hook.overlay`） | その約束を**絵で証明**する | 音なし・スマホ縮小で分かる。画面文字は13字以内で、絵の意味を補う一言 |
| 最初の一言（最初のビート） | 状況を動かす | 0.6秒以内に音を出す。説明せず、当事者として言う |

（2026-11-06 方針: タイトルカードは動画の一番最初に置く。上部の帯で出し続ける表示は使わない）

例（atatame-juyojiko、旧構成）: タイトル「コンビニの温めに説明義務がある世界」／0秒＝おにぎり1個の横に分厚い『加熱に関する重要事項説明書』、画面文字「おにぎりを温めるだけ」／最初の一言「こちら、温めますか？」。

## 2. ビートの役割

| role | 内容 | 目安 |
|---|---|---|
| title | 全画面のタイトルカード。**動画の一番最初**に置き、何のコントかを先に約束する | 0〜1.4秒 |
| hook | タイトル直後の異常、またはその予兆 | タイトル明け〜3秒 |
| rule | ずれたルールは**一つだけ**だと分からせる。説明ではなく行動で | 7秒までに終える |
| escalate | 同じルールの適用が一段ずつ大きくなる（level 1→2→3）。毎回新しい情報がある | 2〜4段 |
| bridge | 反応・動作だけの短いつなぎ | 2.5秒以内、多用しない |
| turn | 登場人物がルールから逃げる／拒否する（だが・だから） | 全体の6〜8割の位置 |
| payoff | 逃げ道にもルールが適用される。冒頭の約束を最大の画で回収 | 全体の6割より後 |
| button | 余韻の一言。冒頭につながるとループ視聴になる | 4秒以内 |

二段目の発見（escalate L2以降）がないネタは尺を伸ばさない。画か台詞が6秒以上変わらない区間を作らない（lint が警告する）。

## 3. フック型（`hook.type`）

- `anomaly-first`: 異常な物・状況を0秒で見せる
- `in-media-res`: 出来事の最中から始める（平手打ち、告白、落下）
- `line-first`: 状況に合わない一言から始める
- `reaction-first`: 驚く顔から始め、原因を直後に見せる
- `payoff-tease`: 最後の画を0秒に一瞬置き、巻き戻して経緯を見せる

## 4. タイトル型（`titlePattern`）

`world`「〇〇が△△な世界」／`too-much`「〇〇すぎる△△」／`consequence`「〇〇したら△△された」／`fake-howto`「正しい〇〇のやり方」／`if`「もしも〇〇だったら」（飽和気味）。
`titleAlternatives` に別の型で2案以上を書いておき、公開後にタイトルを差し替えて比べられるようにする。

## 5. フォーマット（`design.format`）

| format | 中身 | 既定のフック |
|---|---|---|
| institutional-absurdity | 日常の一瞬を手続き・契約にする | anomaly-first |
| literalization | 決まり文句を文字どおり実行する | line-first |
| role-reversal | 立場が入れ替わる | in-media-res |
| escalation-ladder | 小さな要求が段階的に巨大化する | payoff-tease |
| wrong-expert | 日常に異分野の専門家の作法を持ち込む | line-first |

役割の並び・尺の目安・注意点は `catalog/skit-formats.json` にある。新しい型は、実際に作って観客の反応を確認できてから追加する。

## 6. 音

- 仕上がりは -14 LUFS（YouTube の再生基準）。台詞は低域カット・軽いコンプ・2.5kHz付近の持ち上げで聞き取りやすくする（render3d が自動で適用）
- BGMは `music.track`（`catalog/asset-library.json` の music）を `gain` 0.28〜0.4 で敷き、台詞の間は自動で下げる（ダッキング）。台詞の切れ目では戻るので、間が埋まる
- 環境音（低いノイズ）は既定で入れない。必要なら `"ambience": "roomtone"`
- タイトルカードには `title-sting`、回収には `{"music": "cut"}` ＋ `payoff-hit` など、場面転換に音の句読点を付ける
- 回収の瞬間に `{"music": "cut"}` で音楽を止めると「間」が立つ。`{"music": "resume"}` で戻す
- 効果音は画面上の出来事にだけ付ける（`catalog/sfx3d.json`）

## 7. 公開後に見るもの

YouTube Studio の Stayed to watch（何%が見続けたか）、平均視聴率、離脱の山、リプレイ。タイトルを差し替えたら、その日付を記録して前後を比べる。予測で「伸びる」と書かない。
