# 見本を測って再現する（Reference replication）

伸びているショートの「見た目とテンポ」を、言葉ではなく**数値**で受け取って再現するための道具と手順。
着想は note「YouTubeショートを Claude Code で量産する」（清水すばる氏, 2026-10-09）。この repo 向けに、Phaser / Shorts v3 / FFmpeg の構成へ置き換えてある。

## 考え方

- 「こういう動画にして」と言葉で頼むと、形は似ても、文字の位置・枠の大きさ・出る速さ・声の間が少しずつずれて素人っぽく見える。
- 見本を**定規として使う**。コマごとに測って数値にし、`productions/<id>/` のデータへ書く。ずれは出来上がりと見本を並べて数値で確かめる。
- 見本は測るためだけに使う。出来上がりの動画に入れるのは自分の台本・素材・声だけ（見本のフレームや音声は出力にもコミットにも含めない。`outputs/` は git 管理外）。
- 自動で出るのは technical な近さまで。見た目とテンポが良いかの最終判断（editorial）は、見て聞いた人が行う。

## 使う前に確認すること

- 見本は、自分で作った動画、または型・間・レイアウトの研究として参照する動画に限る。他人の映像・画像・音声を出力へ持ち込まない。
- テンプレートで量産しただけで中身に違いがない動画は、YouTube の収益化ポリシー（独自性のないコンテンツ）に抵触しうる。型は同じでも、ネタ選びの理由や自分の見解を毎回入れる。
- 声のライセンス（VOICEVOX はクレジット表記、AquesTalk は収益化時に有償ライセンス等）は声ごとに確認する。

## 道具: `tools/reference/reference.py`

依存: `ffmpeg` / `ffprobe`、Python の `numpy` と `Pillow`。

```
# 1. 見本を測る: コマ・動きの量・カット点・声の間・コンタクトシート
python tools/reference/reference.py measure reference/見本.mp4
#   -> outputs/reference/見本/reference-report.json, contact-sheet.jpg, frames/

# 2. 部品を1つ追う: 色を指定して、コマごとの位置と大きさ、動きのイージング推定
python tools/reference/reference.py track reference/見本.mp4 --color '#ff3366'
#   -> outputs/reference/見本/track-ff3366.json（座標は元動画のピクセル）

# 3. 出来上がりと見本を並べる: 見た目の近さ・差の大きい瞬間・声の間の比
python tools/reference/reference.py compare reference/見本.mp4 outputs/shorts/<id>/video.mp4
#   -> compare.md, compare-report.json, worst-frames.jpg（見本｜出来上がり｜差分）
```

- `measure` の `speech.gaps` は無音区間（声と声の間）。`medianGap` が「テンポ」の基準になる。
- `track` の `easingY` / `easingX` は、動き出しから到着までを `linear` / `ease-in-quad` / `ease-out-quad` / `ease-in-out-quad` / `ease-out-cubic` / `ease-out-back` に当てた推定。弾む動き（`ease-out-back`）は冒頭のポンという動きの判定に使える。
- 色の追跡は、背景と区別できる単色の部品（枠・文字の色・順位の数字など）で効く。写真の中の物は追えない。
- 動作確認: `python tools/reference/smoke_test.py`（合成映像のみ。CI でも実行）。

## 頼み方の型（Claude Code / エージェントへ）

### 1. まず1本作る（形を出す）
テーマ、使う素材の置き場所と中身、声の割り当て、最後の一言、縦型 MP4 まで書き出すこと、を**1回でまとめて**伝える。

### 2. 見本を置いて、「部品ごと・位置と速さまで」と1文添える
見本を `reference/` に置き、次の趣旨で頼む（言い回しは自由。大事なのは粒度の指定）。

> 見本の動画を `reference.py measure` / `track` で測り、画面を部品（背景・タイトル・順位・コメント枠・素材）に分けて、位置関係と、出る・動く速さの変わり方まで数値で再現してください。台本と素材は今のままにして、先に冒頭を合わせてから全体を仕上げ、前の MP4 は残したまま新しい MP4 を書き出してください。

「丸ごとコピーして」では測る対象が決まらない。真似てほしい要素は**名前で**伝える:

| 要素 | 伝え方の例 |
|---|---|
| フォント（書体） | テロップの書体と字間・行間を見本に合わせる |
| 色味 | 画面全体の色合い（カラーグレーディング）を見本に合わせる |
| エフェクト | 文字や画像が出る動き（強弱・弾み）を見本に合わせる |
| タイミング | 出る・消えるコマを 0.1 秒刻みで測って合わせる |
| 演出 | 見せる順番と構成を見本に合わせる |
| 被写界深度 | 実写系のとき、背景のぼけ具合を合わせる |

名前が分からない場面は、そのコマを撮ってエージェントに見せ、「これは何と呼ぶ？」と聞けばよい。

### 3. 声の間は別に頼む（見た目を合わせても声のテンポは変わらない）
> 語尾は削らず、話し終わってから次が始まるまでの待ち時間だけを短くしてください。話す速さは変えず、コメントの出るタイミングと順位の切り替えも合わせてください。`reference.py compare` の声の間（`medianGapRatio`）が 1.0 に近づくまで調整し、新しい MP4 で書き出してください。

早口にするのではなく**待ち時間だけ**を詰める。語尾が切れず、テンポだけが一段速くなる。

### 4. うまくいった作り方を、担当ごとのスキルに残す
決めた数値（位置・大きさ・イージング・間の長さ）は `productions/<id>/` のデータとスキルに書いて、次の動画は「このテーマで作って」の1文で回せる状態にする。担当は 構成（テーマ→順位・台本）／素材集め（用意して確認）／音声と書き出し（声・間詰め・MP4）の3つに分ける。このスキルは `.claude/skills/reference-replication/SKILL.md`。

## Shorts v3 との関係

- Shorts v3（`docs/shorts-v3.md`）は実映像を主役にする footage-first の型で、全画面映像＋同期字幕。見本の「部品」が少ないため、使うのは主に `measure`（カット点・声の間）と `compare`（テンポの確認）。
- ランキング型・図解型のように、背景・タイトル・枠・順位といった**部品が画面を構成する動画**では `track` が効く。部品の座標は `productions/<id>/` のデータに書き、runtime に動画固有の分岐を足さない（`AGENTS.md` の再利用ルール）。

## 限界

- `compare` の近さは画素の差に基づく目安で、構図が同じでも素材が違えば下がる。素材が違う比較では「差の大きい瞬間」を見て、部品の位置・タイミングのずれかどうかを人が判断する。
- 色で追えない部品（写真・グラデーション・半透明）は `track` では測れない。その場合は `measure` のコマを見て手で座標を取る。
- 音声の間は無音検出（既定 -35 dB）なので、BGM が大きい見本では `speech.noiseDb` の調整が要る。
