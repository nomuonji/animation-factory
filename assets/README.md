# Reusable asset library

`catalog/asset-library.json` is the machine-readable inventory. `docs/asset-library.md` is the visual and editorial guide.

## Rights and provenance

- The Kenney packs under `kenney/` were downloaded from the linked official pack pages on 2026-09-23. Each pack includes its original `License.txt` and is marked CC0 1.0 by Kenney. Preview images containing Kenney branding were excluded from the stock folder.
- The three music files under `music/` came from their individual OpenGameArt pages, each marked CC0. `safe-space-loop.ogg` is an Opus transcode of the source FLAC; the others retain the downloaded Ogg bytes. The catalog records authors, pages and SHA-256 hashes. Credit is optional under CC0, but keeping the author and source in project credits is recommended.
- The four backgrounds under `backgrounds/` were generated for this project with the built-in OpenAI image tool. They are not represented as CC0 or as works by the third-party artists above. Master images and nearest-neighbor 270×480 portrait or 480×270 landscape versions are included.

Keep the source and license metadata when copying these assets into another project. Check the relevant source page again if using a stock file outside this repository years from now.

These are source assets for future productions. The current production JSON schema still supports procedural backgrounds and audio presets; adding a stock file to a production requires a reusable loader or mixer adapter.
