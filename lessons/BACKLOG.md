# レッスンのネタ帳

作ったら `lessons/<id>.json` を書いて、ここから消す。意味は辞書で確認してから書く。

## phrase（言えそうで言えない一言）
- 気にしないで → No worries. / Don't worry about it.
- ちょっと考えさせて → Let me think about it.
- 今ちょっと手が離せない → I'm tied up right now.
- 言いたいことはわかる → I see where you're coming from.
- 様子を見よう → Let's wait and see.
- ついでに → while you're at it
- 念のため → just in case
- 結局〜になった → I ended up 〜ing

## word（ちょっと難しい英単語：B2〜C1）
- procrastinate（先延ばしにする）
- inevitable（避けられない）
- ubiquitous（どこにでもある）
- candid（率直な）
- reluctant（気が進まない）
- tedious（退屈で面倒な）
- resilient（立ち直りが早い・しなやかな）
- ambiguous（あいまいな）
- compelling（説得力のある・引き込まれる）
- feasible（実現可能な）

## vs（どっちを使う？）
- borrow / lend
- say / tell
- rob / steal
- lie / lay
- sensible / sensitive
- economic / economical

## upgrade（very から卒業）
- very hungry → starving
- very big → enormous
- very small → tiny
- very good → excellent / superb
- very bad → terrible / awful
- very angry → furious
- very happy → thrilled
- very scared → terrified
